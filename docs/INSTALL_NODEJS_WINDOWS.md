# Installatie
De volgende instructies zijn voor Windows.

## Benodigdheden
Python 3.12-3.14

## Stap 1: Installeren van Node Version Manager
Download nvm-setup.exe op de releases pagina:
https://github.com/coreybutler/nvm-windows/releases

Open dit bestand en volg de stappen op het scherm

nu is nvm geinstalleerd

## Stap 2: Installeren NodeJS
Open een Terminal

instaleer node
```bash
nvm install 24.13.0
```
activeer node
```bash
nvm use 24.13.0
```
Nodejs is nu geinstaleerd

Met npm kan nu met nodejs gewerkt worden
